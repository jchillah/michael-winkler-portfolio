## Local development

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## GitHub Pages

The included workflow can deploy the repository using GitHub Pages.

After pushing the repository:

1. Open **Settings → Pages**
2. Under **Build and deployment**, select **GitHub Actions**
3. Run or re-run the `Deploy portfolio to GitHub Pages` workflow

Expected project URL:

```text
https://jchillah.github.io/michael-winkler-portfolio/
```
