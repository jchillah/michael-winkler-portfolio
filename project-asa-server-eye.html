ASA Server Eye

ASA Server Eye ist eine veröffentlichte Android-App für ARK: Survival Ascended. Sie zeigt Live-Serverdaten und ermöglicht das Speichern und Verwalten von Favoriten.

Bei Google Play öffnen ↗ Quellcode ↗ Datenschutzerklärung ↗

Veröffentlicht auf Android

Die Android-Version ist im Google Play Store verfügbar. Die folgenden Funktionen beziehen sich auf den veröffentlichten Funktionsumfang: Live-Serverübersicht und Favoriten.

Nachprüfbare Projektinformationen

Serverdaten

Das Repository dokumentiert die offizielle ASA-Serverliste als Datenquelle.

Favoriten

Server lassen sich speichern und verwalten.

Technik

Flutter, Dart, Riverpod, Dio und Firebase-Integration sind im Repository erkennbar.

Struktur

Das Projekt ist in Features wie Auth, Servers, Favorites, Profile und Settings gegliedert.

Visuelle Nachweise

Das Repository enthält App-Icons, Logos und Splash-Screen-Grafiken. In der geprüften Dateiliste wurden keine dedizierten Screenshots der laufenden App-Oberfläche gefunden. Deshalb werden hier keine Icons als angebliche App-Screenshots dargestellt.
